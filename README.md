# MauiAppEvento - Cadastro de Eventos

Projeto desenvolvido em .NET MAUI para a disciplina de Desenvolvimento de Sistemas (Agenda 15 - Etec).

## 📋 Sobre o Projeto
Aplicativo para cadastro e cálculo automatizado de custo total e duração de eventos em dias.
